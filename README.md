## 📖 Overview

**College Timetable Generator** is a web-based scheduling system that automatically generates conflict-free class timetables for colleges and universities.

Instead of spending hours manually arranging classes, teachers, laboratories, and classrooms, administrators can generate optimized schedules in seconds.

The system is designed to minimize timetable conflicts while ensuring proper teacher workload distribution, classroom utilization, and subject allocation.

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/College-Timetable-Generator.git
```

### Open Project

```bash
cd College-Timetable-Generator
```

### Install Dependencies

```bash
npm install
```

### Configure Database

Create a MySQL database and import the SQL file.

Update the database credentials inside:

```text
db.js
```

### Start Server

```bash
npm start
```

Development Mode

```bash
npm run dev
```
